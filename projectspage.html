Description des tâches réalisées

TeddyTask est un projet de gestion de listes de carte de tâches à réalisées. Il permet aux utilisateurs de créer, modifier et supprimer des tâches, ainsi que de les organiser par catégories. Le projet a été développé en utilisant HTML, CSS et JavaScript pour le front-end, avec une intégration de Figma pour la conception UI/UX. Canva a été utilisé pour la création de visuels et Git pour la gestion du code source.
